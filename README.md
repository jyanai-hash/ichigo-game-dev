# 🍓 いちごシューター

ブラウザですぐに遊べる、いちごテーマのミニ・シューティングゲームです。いちごを左右に動かし、種のショットでむしさんを追いはらいましょう。

## 遊び方

- **移動:** ← / → または A / D
- **ショット:** スペースキー（押しっぱなしで連射）
- **スマートフォン:** 画面下の左右・ショットボタン
- むしさんを倒すと100点。逃したりぶつかったりするとライフが減ります。
- ハイスコアはブラウザーに保存されます。

## 起動方法

`index.html` をブラウザーで開くだけで遊べます。ビルドや依存パッケージは不要です。

## 技術

HTML、CSS、Canvas API、JavaScript（外部ライブラリなし）。
