# ✨ 星詠みのこはく — 幻想シューティング

ブラウザーですぐに遊べる、オリジナルの巫女キャラクター「こはく」が活躍するミニ・シューティングゲームです。星の札を放って、夜空に迷いこんだいたずら妖精たちを追いはらいましょう。

東方Projectの弾幕シューティング作品から着想を得た、オリジナルの世界観・キャラクターによるファンメイドのオマージュ作品です。公式作品のキャラクターや素材は使用していません。

## 遊び方

- **移動:** ← / → または A / D
- **ショット:** スペースキー（押しっぱなしで連射）
- **スマートフォン:** 画面下の左右・ショットボタン
- 妖精を倒すと100点。逃したりぶつかったりすると残機が減ります。
- ハイスコアはブラウザーに保存されます。

## 起動方法

`index.html` をブラウザーで開くだけで遊べます。ビルドや依存パッケージは不要です。

## キャラクター

**星詠みの巫女・こはく** — 星の札を使って、神社の夜空を守る女の子。立ち絵はこのリポジトリ内のオリジナルSVGです。

## 技術

HTML、CSS、Canvas API、JavaScript（外部ライブラリなし）。
