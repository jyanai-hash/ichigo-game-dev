# ✨ 星詠みのこはく — 幻想シューティング

ブラウザーですぐに遊べる、オリジナルの巫女キャラクター「こはく」が活躍するミニ・シューティングゲームです。星の札を放って、夜空に迷いこんだいたずら妖精たちを追いはらいましょう。

東方Projectの弾幕シューティング作品から着想を得た、オリジナルの世界観・キャラクターによるファンメイドのオマージュ作品です。公式作品のキャラクターや素材は使用していません。

## 遊び方

- **移動:** ← / → / ↑ / ↓ または W / A / S / D
- **低速移動:** Shift キー（狙いをつけやすい低速モード）
- **ショット:** スペースキー（押しっぱなしで連射）
- **ボム:** X キー（初期3発。画面内の敵弾を消し、敵を一掃）
- **スマートフォン:** 画面下の方向・ショット・低速・ボムボタン
- 妖精を倒すと100点。逃したりぶつかったりすると残機が減ります。
- 敵を倒すとランダムでアイテムを落とすことがあります。拾うと以下の攻撃強化を獲得します。

## 武器・強化アイテム

- **星弾（初期武器）:** 前方へまっすぐ飛ぶ基本ショット。
- **速射（⚡）:** 弾速が上がり、連射間隔も短くなります。
- **三連（✿）:** 前方へ撃つ弾が増え、最大5発の扇状ショットになります。
- **弾種変更（◆）:** 星弾・光玉・札の順に弾の見た目が切り替わります。
- **前後攻撃（↕）:** 前方ショットに加えて、後方にも弾を撃てるようになります。
- 強化はそのプレイ中に蓄積し、ゲームオーバーまたは再スタートで初期状態に戻ります。

## フェーズ

- **フェーズ1:** 妖精や幽霊が登場します。
- **フェーズ2:** 敵を12体倒すか、開始から45秒経過すると移行。別種の妖怪が現れ、プレイヤーを狙って弾を撃ってきます。敵にはHPがあり、撃破すると通常より多く得点できます。

## 起動方法

`index.html` をブラウザーで開くだけで遊べます。ビルドや依存パッケージは不要です。

## キャラクター

**星詠みの巫女・こはく** — 星の札を使って、神社の夜空を守る女の子。立ち絵はこのリポジトリ内のオリジナルSVGです。

## 技術

HTML、CSS、Canvas API、JavaScript（外部ライブラリなし）。
