# ✨ 星詠みのこはく — 幻想シューティング

ブラウザーですぐに遊べる、オリジナルの巫女キャラクター「こはく」が活躍するミニ・シューティングゲームです。星の札を放って、夜空に迷いこんだいたずら妖精たちを追いはらいましょう。

東方Projectの弾幕シューティング作品から着想を得た、オリジナルの世界観・キャラクターによるファンメイドのオマージュ作品です。公式作品のキャラクターや素材は使用していません。

## 遊び方

- **移動:** ← / → / ↑ / ↓ または W / A / S / D
- **低速移動:** Shift キー（狙いをつけやすい低速モード）
- **ショット:** スペースキー（押しっぱなしで連射）
- **ボム:** X キー（初期3発。画面内の敵弾を消し、敵を一掃してアイテムを自動回収）
- **難易度:** 出撃前に「かんたん」「ふつう」「むずかしい」「おにモード」から選びます。難易度は保存され、「ふつう」「むずかしい」「おにモード」は現在同じ難易度です。かんたんでは敵・敵弾・ボスとの接触で残機は減らず、1回の被弾につきスコアが100点減ります。
- **一時停止:** Esc キー。一時停止画面から再開、ステージ選択、最初から再開、現在のフェーズのやり直しができます。
- ステージ選択と「最初からやりなおし」は新しいプレイとして開始します。「このフェーズをやりなおし」は現在のフェーズ（ボス戦中ならボス戦）を最初から開始し、スコア・残機・ボム・武器強化を引き継ぎます。
- ゲームオーバー後は「コンティニュー」か「あきらめる」を選びます。続けると現在のフェーズから再開し、スコアは0、残機とボムは各3、速射・拡散・後方攻撃・光玉・札はそれぞれ2レベル下がります（最低Lv.1）。
- 5面のボスを倒すと全ステージクリア画面で終了し、プレイ中の更新で結果が上書きされたり、1面へ戻ったりしません。
- **スマートフォン:** 画面下の方向・ショット・低速・ボムボタン
- 妖精を倒すと100点。敵を画面外に逃すと100点減点されます。かんたん以外では敵や敵弾にぶつかると残機が減り、かんたんでは残機の代わりにスコアが100点減ります。
- スコアが2万点に達するごとに残機が1つ増えます。残機は最大5つまでです。
- 敵を4体倒すごとにアイテムが1つ出現します。通常敵から出るアイテムのうち、光玉と札はそれぞれ2%の確率です。中ボス・ボスを倒すと、光玉か札を必ず1つ獲得します。速射・拡散・後方攻撃の強化と移動速度アップ（最大540）も入手できます。レアアイテム「星の加護」は8秒間移動と連射を強化し、取得時に2.5秒間バリアを張ります。
- 撃破数条件を満たすと新しい敵の出現が止まり、画面に残っている敵を倒してから2秒後に次のフェーズへ進みます。
- 雑魚敵はフェーズごとに編隊順・移動・攻撃を設定しています。出現後に予備時間を置いてから自機の現在位置を狙い、攻撃の合間には移動・停止時間を設けます。敵が画面に残っている間は次の編隊を出にくくし、同時に出現する敵数も制限します。
- 雑魚敵の弾幕には自機狙いの連射、扇状・全方向弾、減速後に再加速する弾、時間差で広がる爆発弾、追尾弾、画面端で反射する弾があります。

## 武器・強化アイテム

- **星弾（初期武器）:** 常に発射する基本ショット。光玉や札を拾っても星弾は切り替わらず、引き続き併用して撃ちます。
- **速射（⚡）:** レベルごとに弾速が上がり、連射間隔が短くなります。連射速度は従来の1.5倍です。
- **拡散（✿）:** レベルが1つ上がるごとに前方ショットが1発ずつ増えます。レベル1で1発、最大レベル10で10発になり、レベルに応じて扇の幅も広がります。
- **光玉（●）:** 専用アイテムを拾うとゲージが蓄積し、レベルアップごとにこはくの周囲を回る大きな光玉が増えます。接触した敵にダメージを与え、最大5個です。
- **札（▰）:** 専用アイテムを拾うとゲージが蓄積し、レベルアップごとに発射数が増えます。札は近くの敵へ向きを変えて追尾します。最大5発です。
- **後方攻撃（↕）:** レベル2から後方ショットが始まり、最大5発になります。レベル7以降は弾速も上がります。
- 速射・拡散・後方攻撃・光玉・札は別々のレベルとゲージで強化され、同時に重ねて効果を発揮します。次のレベルに必要なアイテム数はレベル2で1個、レベル3で3個、以降2個ずつ増えます。速射・拡散・後方攻撃はレベル10、光玉・札は最大5発（レベル6）が最大です。現在のレベルとゲージはゲーム画面上部で確認できます。
- 強化はそのプレイ中に蓄積し、ゲームオーバーまたは再スタートで初期状態に戻ります。
- **移動速度アップ（➤）:** 拾うごとに移動速度が上がります。最大速度は540です。
- **星の加護（✦・レア）:** 8秒間、移動速度と連射速度が上がります。取得時には2.5秒間のバリアも発動します。残り時間は装備欄の下に表示されます。

## ステージ

各ステージは6フェーズとステージボスで構成されます。撃破数の条件を満たした後、画面内の敵をすべて倒すと2秒後に次へ進みます。画面上部のPHASE表示は「ステージ-フェーズ」です。

### 1面 — 夜桜の神社

- **フェーズ1:** 妖精や幽霊を36体倒すと次へ進みます。開始から45秒経過した場合は撃破数にかかわらず進行します。
- **フェーズ2:** 妖怪を48体倒すか、開始から100秒経つと中ボス戦へ進みます。敵の攻撃頻度は少し控えめです。
- **フェーズ3:** 中ボス「星喰いの鬼」が登場します。撃破すると2500点とボム1発を獲得します。その後、敵を48体倒すと次へ進みます。
- **フェーズ4:** コウモリ妖怪の左右編隊、狐妖怪、影コウモリの後、3種類の混成編隊が繰り返し現れます。各編隊の敵がいなくなってから次の編隊が出現します。54体倒すと次へ進みます。
- **フェーズ5:** 海月や蝶の妖怪が現れます。60体倒すと次へ進みます。
- **フェーズ6:** 竜や星の妖怪が現れます。72体倒すと1面ボス戦です。
- **1面ボス「夜桜の大妖狐」:** 扇状弾・弧状弾・全方向弾、予告線つきの突進を使い、約6秒間の無敵弾幕必殺技を最大3回繰り出します。必殺技は回ごとに変化し、使用後は通常攻撃パターンも切り替わります。各必殺技の後には妖狐の眷属を召喚します。HPは画面に数値表示され、撃破後は1面クリア演出を挟んで2面へ進みます。

### 2面 — 深海と氷海

- **フェーズ1:** 小魚妖怪は左右から群れで侵入して中央で反転し、自機狙いの水弾を1発撃ちます。海月妖怪はゆっくり蛇行しながら下降して5方向の泡弾を発射し、深海妖精は画面上部で停止してから斜め下へ離脱しつつ3方向の水弾を撃ちます。36体倒すと次へ進みます。
- **フェーズ2:** 蟹妖怪は左右に揺れながら下降し、途中で停止してから自機狙いの氷弾を2連射します。熱帯魚妖怪は大きな弧を描いて移動し、5方向の水弾を発射します。氷結妖怪は上部で停止後にゆっくり下降し、途中で減速する3方向の氷弾を撃ちます。48体倒すか、開始から100秒経つと中ボス戦へ進みます。
- **フェーズ3:** 中ボス「星喰いの鬼」が再び立ちはだかります。通常攻撃1「星喰いの三連撃」は、0.5秒停止後、こはくを狙う向きを変えながら0.25秒間隔で星弾の円を3回（各48発）放ち、左右に移動します。この攻撃を5回繰り返してから、通常攻撃2「鬼火の輪」へ移ります。鬼火の輪は16方向の弾を2秒間隔で角度を45度ずらして2回放ち、通常弾の1.5倍の外周に赤紫の炎をまとった鬼火も広がります。炎の鬼火は発射から1秒後、進んだ位置を中心に赤紫の弾を16方向へ放ちます。必殺技「星喰いの大輪」では鬼が(400, 130)へ移動して停止し、1秒間の予告中に円形エフェクトを表示します。予告終了時に星型弾12発（30度間隔、160px/s）、1秒後に星型弾6発（60度間隔、基準角度+15度、190px/s）、さらに1秒後に火球8発（45度間隔、130px/s）を発射し、技後1.5秒間停止します。通常攻撃1から繰り返し、戦闘中は画面上部から青い玉もランダムな位置・間隔で落ちてきます。移動は滑らかに行われます。撃破すると2500点とボム1発を獲得し、敵を48体倒すと次へ進みます。
- **フェーズ4:** イカ妖怪は左右に移動しながら下降し、途中で停止して左右反転します。5方向の墨弾を発射します。イルカ妖怪は画面下部から上昇し、画面上部で反転して下降しながら自機狙いの水弾を2連射します。泡妖怪は画面上部で停止後に左右へ移動し、途中で減速する6方向の泡弾を発射します。54体倒すと次へ進みます。
- **フェーズ5:** 貝妖怪は画面上部で停止してから、ゆっくり下降しながら3方向の氷弾を発射します。珊瑚妖怪は左右に大きく揺れながら下降し、5方向の水弾を撃ちます。真珠妖怪は画面上部で停止し、一定時間後に下降しながら8方向の泡弾を発射します。泡弾は発射後に加速します。60体倒すと次へ進みます。
- **フェーズ6:** 鮫妖怪は左右に分かれて高速で侵入し、中央を避けたランダムな位置で1秒停止してからこはくの位置へ高速突進します。深海竜妖怪は画面上部を左右に移動して停止した後、下降しながら7方向の氷弾を発射します。深海妖怪は画面上部で停止してからゆっくり下降し、9方向の泡弾を通常速度の3倍で発射します。泡弾は発射0.5秒後から0.5秒かけて通常速度の0.5倍まで減速します。72体倒すと2面ボス戦です。
- **2面ボス「深海の氷龍」:** 氷の扇弾や回転する泡弾を放ち、必殺技では氷海の弾幕と深海の眷属を召喚します。撃破するとゲームクリアです。

### 3面 — 紅蓮火山

- **フェーズ1〜2:** 火山地帯の妖怪が段階的に現れます。
- **フェーズ3:** 火山妖怪は左右から侵入して中央で反転し、自機狙いの火弾を3連射します。溶岩妖怪は画面上部で停止後に下降しながら7方向の火弾を発射します。火花妖怪は左右に蛇行しながら下降し、5方向の火弾を撃ちます。中ボス戦へ進みます。
- **フェーズ4〜6:** 火山の眷属や溶岩の精が現れます。敵の弾幕が段階的に激しくなり、各フェーズの撃破条件は画面上部に表示されます。
- **3面ボス「灼熱の鳳凰」:** 火の輪を広げる弾幕、狙いを定めた連射、回転する炎弾を使い、必殺技では広範囲の炎弾幕を展開します。必殺技の後には火山の眷属を召喚します。

### 4面 — 月影の竹林

- **フェーズ1〜6:** 月夜の竹林を舞台に、竹林の妖怪や幻惑の蝶が襲来します。中ボスを含む6フェーズを突破するとボス戦です。
- **4面ボス「月影の白鹿」:** 月光を思わせる扇状弾や追尾弾、回転弾を放ちます。必殺技中は月影の弾幕が展開され、終了後には竹林の眷属が現れます。

### 5面 — 星冠の天空城

- **フェーズ1〜6:** 星の回廊と天空城を守る敵との連戦です。中ボスを含む6フェーズを突破すると最終ボス戦です。
- **5面ボス「星冠の天龍」:** 星弾の扇状攻撃や狙い撃ち、回転弾を使い、必殺技では密度の高い星の弾幕を繰り出します。必殺技後には天空城の眷属を召喚します。撃破するとゲームクリアです。

## 起動方法

`index.html` をブラウザーで開くだけで遊べます。ビルドや依存パッケージは不要です。

## デバッグ

URLの末尾に `?debug=1` を付けると、開始画面に開始位置の選択欄が表示されます。全5ステージの各フェーズと各ステージボスから直接開始できます。各ステージのフェーズ3を選ぶと中ボス戦から始まります。通常のゲーム画面では選択欄は表示されません。

## キャラクター

**星詠みの巫女・こはく** — 星の札を使って、神社の夜空を守る女の子。立ち絵はこのリポジトリ内のオリジナルSVGです。
